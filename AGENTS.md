# AGENTS.md

## Основные правила

* Предпочитай идиоматичный Rust(edition 2024) и современные конструкции языка и стандартной экосистемы вместо устаревших паттернов.
* Предпочитать stable Rust.
* Публичные API должны иметь rustdoc, если поведение или инварианты не очевидны.
* Крейт не должен использовать panic или использовать паникующие вызовы других крейтов.
* `unsafe` не добавлять без явного согласования. Любой согласованный `unsafe` должен быть изолирован, задокументирован и покрыт тестами.
* Предпочитать type-driven API, compile-time гарантии и zero-cost.
* Для обычного текста не делай "ручные" переносы на новую строку.

## Тестирование и проверки

Перед завершением изменения, если toolchain доступен, выполнить релевантные проверки:

```bash
cargo fmt --all
cargo clippy --workspace --all-targets --all-features
cargo test --workspace --all-features
```
